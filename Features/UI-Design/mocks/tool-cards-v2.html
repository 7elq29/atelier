What changed
No color unless needed
Success cards are fully monochrome. Only errors get a color signal — a subtle red border tint and red text. Running shows a spinner instead of a colored dot.
Spinner over dot
A spinning border communicates "in progress" without adding a color. Disappears when done — nothing to show for a finished card.
Parsed test output
Test runner output is parsed into aligned columns: spec name, pass/fail, duration. No raw terminal dump.
Parsed TypeScript errors
File path + line on one row, error message indented below. Paths are styled differently from messages for quick scanning.
Read = line numbers
File reads show line numbers in a grid layout. Relevant lines highlighted with a faint red tint when they contain the error.
Edit = diff view
Edits show the removed/added lines with — and + prefixes. Context lines muted. No need to open the file to understand what changed.
